# BoltronX UI Components

Simple, themeable components for **React** and **SolidJS** that work with plain HTML forms and
server rendering, from one repository and one set of styles.

| Package                                                                  | Framework                                     | Readme                                           |
| ------------------------------------------------------------------------ | --------------------------------------------- | ------------------------------------------------ |
| [`@boltronx/react-ui`](https://www.npmjs.com/package/@boltronx/react-ui) | React 19, Next.js (Server Components and SSR) | [packages/react-ui](packages/react-ui/README.md) |
| [`@boltronx/solid-ui`](https://www.npmjs.com/package/@boltronx/solid-ui) | SolidJS, SolidStart (SSR and server actions)  | [packages/solid-ui](packages/solid-ui/README.md) |

Both packages share the same design tokens and component CSS, so an app looks the same whichever
framework it uses. Docs: [boltronx.github.io/ui-components](https://boltronx.github.io/ui-components/).
